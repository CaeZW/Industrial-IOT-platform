Arrancar toda la infraestructura:
    docker compose --env-file .env \
    -f infra/compose/compose.yaml up -d

Detener containers
    docker compose --env-file .env \
    -f infra/compose/compose.yaml stop
*Esto los detiene pero conserva containers y volúmenes.

Arrancar nuevamente
    docker compose --env-file .env \
    -f infra/compose/compose.yaml start

Detener y eliminar containers
    docker compose --env-file .env \
    -f infra/compose/compose.yaml down
*Esto elimina containers/redes de Compose, pero conserva los volúmenes.

Eliminar también los datos
    docker compose --env-file .env \
    -f infra/compose/compose.yaml down -v

2. Ver estado de todos los servicios

    docker compose --env-file .env \
    -f infra/compose/compose.yaml ps

    docker ps

3. Logs generales
    docker compose --env-file .env \
    -f infra/compose/compose.yaml logs

    docker compose --env-file .env \
    -f infra/compose/compose.yaml logs -f
4. Logs de un servicio
* PostgreSQL
    docker logs docker-postgre
    docker logs -f docker-postgre
    docker logs --tail 100 docker-postgre
* Mosquitto
    docker logs docker-mosquitto
* Node-RED
    docker logs docker-nodered
    docker logs -f docker-nodered
5. Entrar dentro de un container
* PostgreSQL
    docker exec -it docker-postgre bash
* Node-RED
    docker exec -it docker-nodered bash
* Mosquitto
    docker exec -it docker-mosquitto sh

7. Mosquitto
* Verificar puertos publicados
    docker compose -f infra/compose/compose.yaml port mosquitto 1883
* Suscribirse
    docker exec -it docker-mosquitto \
    mosquitto_sub \
    -h localhost \
    -p 1883 \
    -t "iot/v1/test/#" \
    -v
* Publicar
    docker exec docker-mosquitto \
    mosquitto_pub \
    -h localhost \
    -p 1883 \
    -t "iot/v1/test/hello" \
    -m '{"message":"hello"}'
8. Node-RED

* Navegador:

* Logs:

* Entrar al container:
